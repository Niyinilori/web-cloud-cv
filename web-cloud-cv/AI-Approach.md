# AI Approach

## Introduction

For this project, I used AI to help me create a basic personal CV website using HTML and CSS.

## How I Used AI

I used AI as a development assistant to help me:

- Plan the structure of the CV website.
- Create the initial HTML structure.
- Create CSS styling for the website.
- Make the website responsive for different screen sizes.
- Understand how HTML and CSS work together.
- Identify and correct mistakes in the code.

## My Approach

I first created a GitHub repository called `web-cloud-cv` and created a local project on my M Drive.

I then used AI to generate an initial HTML structure containing sections for my personal information, education, experience, skills and contact details.

After creating the HTML, I used AI to create CSS styling to improve the appearance of the website.

I reviewed the generated code and made changes where necessary to make the website suitable for my CV.

## What I Learned

Using AI helped me understand how HTML provides the structure of a webpage while CSS controls its appearance and layout.

I also learned how to organise files into a web project and how GitHub can be used to store and manage a project.

## Reflection

AI was used as a support tool rather than simply copying code without understanding it. I reviewed the generated code and used it to learn how the different parts of the website work.
